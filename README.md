# めたたろ英語辞典（Chrome 拡張）

![caver](https://user-images.githubusercontent.com/3032390/148529368-369cbe98-498a-4d1f-a7b4-199430866ff9.png)

ブラウザで読んでいる英語を、その場で引ける英和辞典です。辞書データはすべて拡張の中に入っているので、
引くたびに外部へ通信しません。不規則動詞の表は、これまでどおりタブの 1 つとして残しています。

## できること

- **右クリックで引く**：ページ上の単語を選んで右クリック →「「単語」を辞典で引く」。小さな窓で開きます
- **元の形に戻して引く**：`went` → go、`studies` → study、`better` → good / well
- **検索欄**：前方一致の候補、つづりの近い語の提案（`aple` → apple ほか）、熟語、日本語からの簡易検索
- **熟語をそのまま引く**：`take a walk` のように空白を入れて打つと熟語の項目を開きます（文から写した `?` `.` は外して引きます）
- **変化形の発音**：`risen` で引くと rise の項目を出しつつ、引いた形 risen の発音記号と読み上げも先頭に出します
- **紙の辞書ふうの表示**：発音記号・英検の級の目安・品詞ごとの意味・熟語・例文・関連語
- **重要語の解説**：高校〜大学入試レベルの語について、コアイメージ・場面別の例文・コロケーション・
  類義語との違い・よくある間違い・語源・入試での問われ方（**解説・例文の一部は AI が作成**）
- **読み上げ**：アメリカ英語／イギリス英語、ゆっくり（0.7 倍）。Space または P で見出し語を読みます。見出しの「ゆっくり」か S キーで速さを切り替えます
- **ページを隠さない開き方**：検索欄の横のボタンで、サイドパネルか小さな窓に移せます。設定で「ツールバーのボタンでサイドパネルを開く」にすると、最初からページの横に出ます
- **単語帳・検索履歴（20 件）**・小テスト・意味を隠すモード
- **ページの単語を調べる**：ツールバーのボタンか右クリック →「このページの単語を調べる」。開いているページの英文から、
  収録語を多い順に（英検の級・AI 解説の有無つき）、熟語も一覧にします。変化形は元の形にまとめて数えます
- **ページに印を付ける**：一覧の絞り込みに合う語に下線を引き、押すとその語の項目をサイドパネルで開きます。「印を外す」で元に戻ります
- **一覧を検索で絞る**：ページの単語一覧の上の検索欄に打つと、その文字を含む語・熟語だけに絞ります（級・AI 解説の絞り込みと重ねて使えます）
- **PDF・画像を読む**：PDF や画像（PNG / JPEG / WebP など）を選ぶかドロップすると、同じように単語と熟語を一覧にします。
  文字データの無い PDF（スキャンした参考書など）と画像は、写っている英文を読み取ってから数えます
  （拡張に同梱した pdf.js と Tesseract.js で読み、外へは送りません）
- **印を付けて PDF を開く**：読んだ PDF を拡張の中の画面で開き、辞典に載っている語に薄いマーカーを引きます。
  マーカーの語を押すと、その語の項目をサイドパネルで開きます。Chrome の PDF 表示はどの拡張機能からも読めないため、この画面を使います
- **日本語専用**：画面も辞書の意味も日本語です（日本語を読む人が英語を学ぶための英和辞典）

## 権限

| 権限 | 理由 |
|---|---|
| `contextMenus` | 右クリックメニューから引くため |
| `storage` | 検索履歴・単語帳・設定（読み上げの地域・速さ）を手元に保存するため |
| `activeTab` | 「このページの単語を調べる」を押したタブだけ、押したときだけ本文を読むため |
| `scripting` | そのタブへ本文を読む処理と、印を付け外しする処理を、押したときだけ差し込むため |
| `sidePanel` | 印や一覧の語を押したとき、ページの横に辞典の項目を開くため |

読み上げはブラウザに入っている音声合成（speechSynthesis）を使うので、権限は要りません。
すべてのサイトを読む権限（host 権限 / `<all_urls>`）と、ページに常駐するスクリプトは使っていません。
ページの文字は押したときに 1 回だけ読み、この端末の中で数えるだけで、外へは送りません。
ページを移動すると読む許可は消えるので、移動先ではもう一度ボタンか右クリックから調べます。

## 収録データ

| データ | 中身 | 件数 | ライセンス |
|---|---|---|---|
| [EJDict-hand](https://github.com/kujirahand/EJDict) | 英和辞書の本文 | 47,028 項目 | Public Domain（CC0） |
| [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict) | 発音記号（ARPAbet を IPA へ変換） | 26,756 項目に付与 | BSD 形式 |
| [WordNet 3.1](https://wordnet.princeton.edu/) | 品詞・類義語・反意語・派生語・不規則変化 | 40,098 語 | WordNet 3.1 License |
| [Tatoeba](https://tatoeba.org/) | 英日の例文（短い文を選んで収録） | 46,418 文 / 13,593 語 | CC BY 2.0 FR |
| [CEFR-J Wordlist 1.5 / Octanove Vocabulary Profile C1/C2 1.0](https://github.com/openlanguageprofiles/olp-en-cefrj) | 英検の級の目安（CEFR の段階から割り当て） | 7,436 語 | CC BY-SA 4.0 |
| AI による解説 | 重要語の解説と例文の一部 | 1742 語（順次追加） | MIT（この拡張の一部） |
| AI による熟語 | 句動詞・日常会話・オンライン英会話でよく使う言い回しと例文 | 665 句 / 1,322 文 | MIT（この拡張の一部） |

- ライセンスの全文と変更点は [NOTICE](NOTICE) にあります
- 英検の級は**目安**です。英検が公式に示した語彙表ではありません
- 日本語からの検索は、英和辞書の訳語から逆に引いた簡易的なもので、和英辞典ではありません
- データは頭文字ごとに分けたファイル（`data/dict/a.json` など）で、必要になった分だけ読み込みます

## 構成

```
manifest.json        Manifest V3
background.js        右クリックメニュー・ページの本文の読み取り・サイドパネルを開く
popup.html           画面（サイドパネルでも同じものを使う）
panel.html           サイドパネルの入れ物
js/popup.js          辞書画面（検索・表示・単語帳・小テスト）
js/page.js           「ページ」タブ（ページ・PDF・画像の単語の一覧、印の付け外し）
js/scan.js           本文から収録語・熟語を数える（test/scan.test.js で検査）
js/page-mark.js      ページに印を付ける（押したときだけ差し込む）
js/dict.js           データの読み込み（頭文字ごとに遅延読み込み）
js/lemma.js          変化形を元の形に戻す（WordNet の規則と例外表）
js/speech.js         読み上げ
js/store.js          履歴・単語帳・設定の保存
js/verbs.js, app.js  不規則動詞の表
data/                辞書データ（上の表を参照）
lib/pdfjs/           pdf.js（PDF の文字の取り出し・Apache-2.0）
lib/tesseract/       Tesseract.js（画像の英文の読み取り・Apache-2.0）
icons/fa/            アイコン（Font Awesome Free の SVG・CC BY 4.0。css/icons.css で表示）
_locales/ja/         画面の文言（日本語のみ）
```

## インストール（開発版）

1. `chrome://extensions` を開き、右上の「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選ぶ

抽出ロジックのテストは Node.js だけで動きます（依存パッケージなし）：`node --test test/scan.test.js`
